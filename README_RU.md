# Englishly — персональное приложение для изучения английского

Обновлённая версия веб-приложения/PWA с тёмной темой, анимациями и дополнительными режимами практики. Не требует регистрации, подписки или API-ключей.

## Возможности
- Тёмный интерфейс, анимация экранов, вопросов, нажатий и карточек.
- Карточки слов со свайпом влево/вправо, переводом, транскрипцией и примерами.
- Расширенный словарь (около 100 слов и выражений), поиск и фильтры.
- Режим «Русский → английский»: активное вспоминание слов.
- Режим «Составить предложение»: вводи английский вариант сам; при необходимости открой подсказку с перемешанными словами.
- 6 уроков, озвучивание английских примеров, XP, серия дней, ежедневная цель, достижения и статистика.
- Прогресс сохраняется локально в браузере; поддерживается установка как PWA на главный экран iPhone и кэширование основных файлов для офлайн-режима.

## Как обновить уже опубликованный сайт на GitHub Pages
1. Открой репозиторий `englishly` на GitHub.
2. Нажми **Add file → Upload files** (или перетащи файлы на вкладке Code).
3. Загрузить нужно файлы из папки `english_buddy` в корень репозитория: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`. Не загружай саму папку как вложенную папку.
4. Нажми **Commit changes**. Через минуту-две обнови сайт.
5. Если iPhone показывает старую версию, полностью закрой веб-приложение и открой сайт в Safari снова. Service worker обновлён до `englishly-v2`, чтобы запросить свежие файлы.

## Установка на iPhone
Открой опубликованный HTTPS-адрес в Safari → **Поделиться → На экран «Домой» → Добавить**. Названия пунктов могут немного отличаться в зависимости от версии iOS.

## Примечания
Все упражнения работают локально без платной подписки. Озвучивание использует системный синтез речи браузера. Ответы на задания по предложениям проверяются по вариантам фраз с нормализацией регистра и пунктуации; в английском возможны другие правильные формулировки, даже если они не совпадают с эталоном.
